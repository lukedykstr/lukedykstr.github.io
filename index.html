Apple SceneKit Code Tutorial

Overview

The focus area of this tutorial is SceneKit. SceneKit is a Swift library for creating, managing, and viewing 3D scenes in iOS applications. This tutorial will show you how to implement a 3D puzzle game application using Apple's SceneKit.

The game will feature a start screen, level and difficulty select, and a game scene where the user can drag around 3D puzzle pieces into their correct positions, given a certain amount of time depending on the difficulty.

Getting Started

For your development environment, you will need a Mac running the latest XCode version.

In XCode, create a new project and select the 'Game' template. Ensure that 'SceneKit' is selected under the 'Game Technology' dropdown menu. This will ensure that the SceneKit dependency and anything else you need will be added to the project.

Once the project is created, you can delete the 'art.scnassets' folder with the demo spaceship, and all code within the GameViewController.swift file. You can also delete any storyboard files, as we'll be using SwifUI. You should now have a somewhat empty project with SceneKit all set up and ready to be used.

Coding

ContentView

Create a file called ContentView.swift. This will be the start menu screen of the app. The main outline of the file should look like this:



    import SwiftUI
    import SceneKit

    struct ContentView: View {
        @State private var path = NavigationPath()

        var body: some View {
            NavigationStack(path: $path) {

            }
        }
    }

This sets up our ContentView to have a Navigation Stack so it is able to switch between different views. The next view we'll focus on is the level selection view, so we'll create a new file called LevelViewModel.swift and set is as such:



    import SwiftUI

    @MainActor
    class LevelViewModel: ObservableObject {
        @Published var showLevel: Bool = false // Shows level in ContentView
        @Published var contentViewColor: Color = Color.black // Changes color of ContentView's ZStack
        @Published var confirmedDifficulty: Bool = false // Difficulty confirmed by user
        @Published var sceneToDisplay: String = "" // Contains level to display
        @Published var currentTimer: String = "" // Contains timer based on selected difficulty
    }

  • showLevel tells us whether we should be showing the selected game level or not.
  • contentViewColor defines the background color of uor content view.
  • confirmedDifficulty tells us whether the user has selected a difficulty yet or not.
  • sceneToDisplay is the scene file name of the level we want to display.
  • currentTimer is the remaining time the user has to complete the level based on the difficulty.

We can now create our LevelSelection.swift view:



    import SwiftUI

    struct LevelSelection: View {

                    viewModel.sceneToDisplay = "art.scnassets/level2.scn"

                case "Level 3":
                    viewModel.sceneToDisplay = "art.scnassets/level3.scn"
                    break
                case "Level 4":
                    viewModel.sceneToDisplay = "art.scnassets/level4.scn"

                    break
            }
        }
    }

We now have our level selection and difficulty selection views all set up. We can get started on our GameView, where we will be using SceneKit.

Rather than using an SCNView directly, the default SceneKit view to display a 3D scene, we will be creating a SceneViewWrapper in order to add more functionality, in this case, tap and drag gesture recognition.

Here is the outline of the GameView.swift file to get started:



    import SwiftUI
    import SceneKit
    
    struct GameView: View {
        @EnvironmentObject var level: LevelViewModel
        
        var body: some View {
            SceneViewWrapper()
        }
    }

    struct SceneViewWrapper: UIViewRepresentable {
        @EnvironmentObject var level: LevelViewModel
        
        func makeUIView(context: Context) -> SCNView {
            let sceneView = SCNView()
            
            return sceneView
        }
        
        func updateUIView(_ uiView: SCNView, context: Context) {}
        
        func makeCoordinator() -> Coordinator {
            Coordinator()
        }
        
        class Coordinator: NSObject {
            @objc func handlePan(_ gesture: UIPanGestureRecognizer) {
            
            }
        }
    }

Our main view consists of a SceneViewWrapper, which, right now, just returns a default SCNView and does nothing else.

In the makeUIView function of the SceneViewWrapper, we can load the scene of the level we want to display and add a gesture recognizer accordingly:



    func makeUIView(context: Context) -> SCNView {
        let sceneView = SCNView()
        let scene = SCNScene(named: level.sceneToDisplay)
        
        sceneView.scene = scene
        sceneView.allowsCameraControl = true
        sceneView.autoenablesDefaultLighting = true
        sceneView.antialiasingMode = .multisampling4X
        sceneView.preferredFramesPerSecond = 60
        
        let panGesture = UIPanGestureRecognizer(
            target: context.coordinator,
            action: #selector(Coordinator.handlePan(_:))
        )
        
        sceneView.addGestureRecognizer(panGesture)
        context.coordinator.sceneView = sceneView
        
        return sceneView
    }

Here, we load the level of the scene we want to display provided from the level view model. We set the sceneView's scene with sceneView.scene = scene

We adjust various settings, such as allowing camera control, enabling default lighting, setting the antialiasing mode, and setting the preferred FPS to 60.

Then, we create a new UIPanGestureRecognizer called panGesture.

  • The Coordinator is the class that will be handling the pan gesture, which we will define later. Hence the target: context.coordinator.
  • action: #selector(Coordinator.handlePan(_:)) defines what specific function to call to handle the pan gesture, which will also be defined in the Coordinator class.

Let's move on to defining the Coordinator class in the SceneViewWrapper.

The Coordinator class will have 3 attributes sceneView, selectedNode, and lastHitPosition.

The handlePan function will take our pan gesture recognizer as an argument and use sceneView.hitTest() to determine which object the user has tapped on, if any. In this case, we are only looking at objects with the tag "piece". If an object does not have that tag, which can be defined in the SceneKit Scene Editor, then it won't be recognized and cannot be tapped and dragged.

Here is the Coordinator class in full:



    class Coordinator: NSObject {
        weak var sceneView: SCNView?
        var selectedNode: SCNNode?
        var lastHitPosition: SCNVector3?
        
        @objc func handlePan(_ gesture: UIPanGestureRecognizer) {
            guard let sceneView = sceneView else { return }
            let location = gesture.location(in: sceneView)
            
            if gesture.state == .began {
                let hits = sceneView.hitTest(location, options: nil)
                
                if let hit = hits.first(where: { $0.node.name == "piece" }) {
                    selectedNode = hit.node
                    lastHitPosition = hit.worldCoordinates
                }
            } else if gesture.state == .changed {
                guard let node = selectedNode, let lastPos = lastHitPosition else { return }
                
                let hitResults = sceneView.hitTest(
                    location,
                    options: [SCNHitTestOption.boundingBoxOnly: true]
                )
                
                if let result = hitResults.first {
                    let newPos = result.worldCoordinates
                    node.position = SCNVector3(newPos.x, lastPos.y, newPos.z)
                }
            } else if gesture.state == .ended {
                selectedNode = nil
                lastHitPosition = nil
            }
        }
    }
